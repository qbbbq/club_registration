# 1200 条学生压测数据脚本设计

日期：2026-08-20
状态：已确认

## 目标

提供一个可直接在 MySQL 5.7/8.0 执行的静态 SQL 文件，向现有 `club_registration.students` 表追加 1200 条虚构学生数据，用于报名接口并发压测。

## 设计

- 不执行 `DELETE`，保留现有学生数据。
- 使用单个事务包裹插入。
- 使用 `INSERT IGNORE`，重复执行时跳过已存在的唯一身份证号。
- 生成 1200 个唯一的 18 位身份证号，使用 `900000` 测试区域码，不使用真实个人信息。
- 身份证号包含合法日期、顺序码和校验码，满足项目现有格式校验。
- 姓名使用明确的虚构测试姓名，班级分布在高中年级和班级编号中。
- 脚本只写入 `name`、`id_card`、`class_name`，不修改社团名额或报名记录。
- 脚本末尾输出本批测试身份证前缀对应的记录数量，便于确认执行结果。

## 验收标准

1. SQL 可在 MySQL 5.7/8.0 执行。
2. 脚本包含 1200 条 `VALUES` 数据。
3. 1200 个 `id_card` 唯一且均为 18 位。
4. 重复执行不会因 `students.id_card` 唯一约束失败。
5. 不清空、不覆盖现有学生数据。
