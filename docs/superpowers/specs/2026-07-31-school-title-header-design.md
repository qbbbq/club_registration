# 页面增加「行知中学」标题设计

## 背景

社团报名系统当前各页面仅有业务标题（如「社团报名系统」「社团报名」「后台管理系统」「社团名额统计」），缺少学校品牌标识。用户要求在所有页面统一添加「行知中学」标题。

## 目标

1. 所有页面（Home、Register、Login、Admin、Stats）统一显示「行知中学」。
2. 校名作为主标题，原业务标题降为副标题（方案 A：主标题 + 副标题模式）。
3. 纯前端模板与样式改动，不涉及后端、接口、数据与测试逻辑变更。

## 非目标

1. 不改变页面布局结构（居中卡片/顶部条布局保持不变）。
2. 不做全站固定导航条（方案 C 已否决）。
3. 不修改路由、登录逻辑、后端接口。

## 设计

统一模式：「行知中学」为主标题（加粗、深色），原业务标题为副标题（灰色、字号略小）。

### Home.vue（居中卡片）

- 主标题：`行知中学`，28px，加粗，深色 `#303133`
- 副标题：`社团报名系统`，16px，灰色 `#606266`（新增，位于主标题之下）
- 原 `tip`（"请扫描下方二维码进入报名"）不变，仍显示在副标题之下

### Register.vue（居中卡片）

- 主标题：`行知中学`，28px，加粗
- 副标题：`社团报名`，16px，灰色

### Login.vue（居中卡片）

- 主标题：`行知中学`，28px，加粗
- 副标题：`后台管理系统`，16px，灰色
- 原 `login-tip`（"请输入管理员账号密码登录"）保留

### Admin.vue（顶部条 header-left）

- 主标题：`行知中学`，24px，加粗
- 副标题：`社团管理后台`，16px，灰色，紧随主标题

### Stats.vue（顶部条 header）

- 主标题：`行知中学`，24px，加粗
- 副标题：`社团名额统计`，16px，灰色，紧随主标题

## 样式约定

- 主标题颜色统一 `#303133`（与现有一致）
- 副标题颜色统一 `#909399`（与现有提示文字一致）
- 两行间距 4-8px

## 验证

1. 浏览器打开各页面，确认主/副标题层级与内容正确。
2. 运行 `pnpm test`，确认现有测试不受影响。
3. 运行 `pnpm run build`，确认类型检查与构建通过。
