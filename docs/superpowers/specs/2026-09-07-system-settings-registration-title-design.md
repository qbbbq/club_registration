# 系统设置与报名入口标题设计

## 背景

后台当前使用“报名设置”作为 tab 名称，页面只管理报名开放时间。二维码入口页和报名页的副标题分别固定为“社团报名系统”和“社团报名”，无法由管理员统一调整。

本次需求将该 tab 改为“系统设置”，增加报名入口标题配置，并让二维码入口页与报名页使用同一个标题。

## 目标

- 将后台“报名设置”tab 改名为“系统设置”。
- 在系统设置中增加“报名入口标题”配置。
- 二维码入口页和报名页统一使用后台配置的副标题。
- 未配置或清空时使用默认标题“社团报名系统”。
- 保留现有报名开放时间功能和接口兼容性。

## 非目标

- 不修改主标题“行知中学”。
- 不修改浏览器标签页标题。
- 不修改二维码实际内容，二维码仍只指向 `/register`。
- 不新增数据库表。
- 不改变报名开放时间的业务规则。

## 数据与接口

继续复用现有 `settings` 表，新增配置键：

- `registration_title`

默认值由服务端和前端共享约定为：

- `社团报名系统`

新增接口：

### `GET /api/settings/registration-title`

返回：

```json
{
  "success": true,
  "data": {
    "title": "社团报名系统"
  }
}
```

当数据库没有配置，或配置值为空/仅包含空白字符时，返回默认标题。

### `PUT /api/settings/registration-title`

请求：

```json
{
  "title": "2026 秋季社团报名"
}
```

规则：

- 服务端去除首尾空格。
- 非空标题保存到 `settings` 表。
- 空字符串、空白字符串或 `null` 删除该配置并恢复默认标题。
- 标题最多 30 个字符，超出时返回 HTTP 400。
- 原有 `/api/settings/registration-open-time` 接口保持不变。

## 页面行为

### 后台

- tab 文案从“报名设置”改为“系统设置”。
- 保留报名开放时间设置区块。
- 增加报名入口标题设置区块：
  - 输入框显示当前标题，默认显示“社团报名系统”。
  - 最大长度为 30 个字符。
  - 允许清空。
  - 保存成功后显示成功提示并同步本地状态。
  - 保存失败显示错误提示，不覆盖当前有效值。

### 二维码入口页

- 主标题继续显示“行知中学”。
- 副标题由固定文字改为后台配置标题。
- 加载期间和读取失败时使用默认标题。
- 二维码仍然指向当前报名页面 `/register`。

### 报名页

- 主标题继续显示“行知中学”。
- 副标题由固定“社团报名”改为后台配置标题。
- 加载期间和读取失败时使用默认标题，不阻塞报名流程。

## 实现结构

- 服务端在 `settings.ts` 中增加标题常量、读取接口、保存接口和输入校验。
- 前端新增共享设置工具，例如 `src/utils/registrationSettings.ts`，集中定义默认标题和标题读取逻辑。
- `Home.vue` 与 `Register.vue` 在挂载时调用共享逻辑读取标题。
- `Admin.vue` 增加标题状态、加载和保存逻辑，并将现有“报名设置”区域改为“系统设置”。
- 沿用现有 `axios`、Element Plus 表单和消息提示模式，不引入新依赖。

## 错误处理与兼容性

- 标题接口读取失败时，前台保留默认标题并继续渲染页面。
- 标题保存失败时，后台保留当前输入状态，提示管理员重试。
- 历史数据库没有 `registration_title` 行时无需迁移，直接返回默认值。
- 现有报名开放时间数据和接口不受影响。

## 测试与验收

服务端测试覆盖：

- 无配置时返回默认标题。
- 有配置时返回保存标题。
- 保存并覆盖标题。
- 空值/空白值清除配置并恢复默认值。
- 超过 30 个字符时拒绝保存。

前端测试覆盖：

- 后台 tab 文案为“系统设置”。
- 标题输入框最大长度为 30。
- 二维码页和报名页使用同一共享标题配置及默认值。

最终验证：

- 全量 Vitest 测试。
- `npx vue-tsc --noEmit`。
- `corepack pnpm run build`。
- 浏览器检查后台保存自定义标题后，二维码入口页和报名页显示一致；清空后恢复默认标题。
